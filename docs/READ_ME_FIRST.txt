❓ TROUBLESHOOTING

  Q: Backend not starting?
  A: Check PostgreSQL is running: psql -U postgres -c "SELECT 1;"

  Q: Can't connect to database?
  A: Run: createdb coupon_db && psql -U postgres -d coupon_db -f schema.sql

  Q: Frontend not loading?
  A: Check backend is running at http://localhost:8000/api/health

  Q: API calls failing?
  A: Check browser console (F12) for errors and API URL configuration

  Q: Port already in use?
  A: Use different port: python -m http.server 8080

  For more: See QUICK_START.md "Troubleshooting" section
